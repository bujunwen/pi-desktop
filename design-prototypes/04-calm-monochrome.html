重塑 macOS 体验 / pi-desktop

PI DESKTOP / DESIGN

少一些界面，多一些专注。

一个克制的、以内容为中心的 Agent 工作空间。

我喜欢更极简的方向，不要太多面板和颜色。让它像真正的 macOS 应用。

PI · 8 秒前

让结构本身成为设计。

这一版只保留黑、白和少量灰阶。左侧图标栏负责全局导航，会话栏保持窄而安静；主画布使用更大的留白，让长内容依然容易阅读。

动画不应该提醒用户“这里有动画”，而应该让状态变化显得自然。
Navigation     reduced 28%
Visual noise   reduced 42%
Content width  capped at 760px

Composer 保持悬浮，但材质更实，不依赖强烈毛玻璃。所有交互统一使用 220ms 的轻微位移与透明度变化。
